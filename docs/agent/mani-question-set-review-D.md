## D. How to run Priveo (sources: `CLAUDE.md`, `apps/mobile/tool/`)

| # | Question | Golden answer | Source | Decision | Notes |
|---|---|---|---|---|---|
| 41 | How do I lint and test the API? | From the repo root: `cd services/api && .venv/Scripts/python -m ruff check . && .venv/Scripts/python -m pytest -q` on Windows (`.venv/bin/python` on macOS or Linux; only the OS path differs). Export the contract with `scripts/export_openapi.py`. | `CLAUDE.md` build and test commands | Keep | Windows and macOS paths both correct |
| 42 | How do I run the PostgreSQL checks, and what must I never do? | From `services/api`, run `.venv/Scripts/python scripts/test_postgres.py` (`.venv/bin/python` on macOS or Linux). It creates, tests and stops a disposable local cluster. Set `POSTGRES_BIN` for another PostgreSQL installation. Never use an application database as `TEST_DATABASE_URL`, because the test fixtures drop its tables. | `CLAUDE.md` | Keep | Windows and macOS paths both correct |
| 43 | How do I run all the checks at once? | `tools/dev/check-local.sh` from the repo root: API on SQLite and PostgreSQL, mobile, web and the Playwright browser tests. Add `--changed` to run only the stages a diff touches. Run it before every push. | `CLAUDE.md` | Keep | |
| 44 | How do I check the web portal? | From `apps/web`: `npm run lint`, `npm test` and `npm run build`. | `CLAUDE.md` | Keep | |
| 45 | How do I check the Flutter app, and when must I regenerate files? | `cd apps/mobile && flutter analyze && flutter test`. After changing `docs/brand/tokens.json` run `dart run tool/gen_theme.dart`. After changing `lib/l10n/app_en.arb` run `flutter gen-l10n`. After `packages/api-contract/openapi.json` changes run `dart run tool/gen_api.dart`. CI fails if generated output is stale. | `CLAUDE.md`; `tool/gen_theme.dart`, `tool/gen_api.dart` | Keep | |
| 46 | How do I build and run the app on a simulator or emulator? | `apps/mobile/tool/build_local.sh android` or `ios`. Flags: `--build-only`, `--clean`, `--env test\|prod`, `--api <url>`, `--local`, `--replay`, `--debug\|--release`, `--device <id>`. The default API is test. | `tool/build_local.sh` | Keep | |
| 47 | How do I point the app at the API running on my Mac? | Use `--local` with `build_local.sh`. It uses the API from `tools/dev/run-local.sh` (Android emulator at `10.0.2.2`, iOS Simulator at `localhost`). It needs a debug build, so it cannot be combined with `--release`. | `tool/build_local.sh` | Keep | |
| 48 | How do I build an installable app for the test or production API? | `apps/mobile/tool/build_release.sh <android\|ios> <test\|prod>`. Files go to `apps/mobile/dist/` as `priveo-test-<version>.apk` or `priveo-release-<version>.apk` (iOS: `...-ios-sim.zip`, or `.ipa` with `--ipa`, which needs Apple signing that is not set up). Test uses flavor `envtest` (package `in.priveo.app.test`, "Priveo Test") and prod uses flavor `prod` (`in.priveo.app`, "Priveo"), so both install side by side on Android. | `tool/build_release.sh` | Keep | |
| 49 | How is the app version raised, and how do I put a build on a phone? | `bump_version.ps1` (run by `push_apk.ps1` before every build) raises PATCH by 1 when fewer than 100 app-code lines changed, and MINOR by 1 (PATCH back to 0) at 100 or more. The build number is MAJOR×10000 + MINOR×100 + PATCH. `push_apk.ps1` builds a release app (add `-Debug` for debug) and copies the APK to the Downloads folder of the phone plugged in by USB; the default API is `https://priveo-api.vercel.app`, changed with `-ApiUrl`. | `tool/bump_version.ps1`, `tool/push_apk.ps1` | Keep | Both are PowerShell scripts |
| 50 | How do changes reach the test and production servers? | Merging to `main` deploys to test. A `v*` tag or a manual run deploys to production after a reviewer approves. Settings are in the GitHub Environments `test` and `production` (`docs/build-and-release.md`). The API runs as two Vercel projects, `priveo-api-test` and `priveo-api-prod`, each with its own Supabase database in Mumbai. Database changes go through a hand-written Alembic migration in `services/api/migrations/versions`. | `CLAUDE.md` | Keep | |
