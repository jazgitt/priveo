### MCP Servers to Activate
- [ ] Vercel (plugin_vercel_vercel) — deploys, logs and project settings for the admin portal. Install the Vercel plugin with `/plugin`, then sign in to Vercel. Ask the repo owner for team access.

### Skills to Know About
- /plugin and /reload-plugins — install and reload plugins. Load the requirements mod with `claude --plugin-dir tools/priveo-reqs`.
- /priveo-status — side pane with stage counts, open bugs and a role and area breakdown.
- /fstatus — track each requirement ID through its stages in `docs/feature-status.json`.
- /ids and /open — check requirement IDs and list open items.
- /context and /usage — check context and usage. /clear resets the session.
- /plan — plan before building.
